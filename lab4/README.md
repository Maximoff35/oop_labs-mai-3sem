# Лабораторная работа №4

Вариант 15. Мир A — плоские многоугольники (`Triangle`, `Square`, `Pentagon`).

Программа реализует иерархию геометрических фигур с абстрактным базовым классом `Polygon`, виртуальными методами и полиморфной коллекцией `PolygonCollection`. Фигуры задаются вершинами в порядке обхода. Главная характеристика `metric()` — площадь, вычисляемая по формуле шнурка; центр — среднее арифметическое координат вершин.

Индивидуальное задание варианта 15 — `containsPoint(Point)` с проверкой принадлежности точки многоугольнику лучевым алгоритмом. Точки на границе считаются принадлежащими фигуре.

## Что реализовано

Контракт классов:

| Класс | Назначение | Основные методы |
|---|---|---|
| `Polygon` | Абстрактный базовый класс; хранит `std::vector<Point>` | `metric`, `center`, `containsPoint`, `print`, `read`, `clone`, `operator double`, `operator==` |
| `Triangle` | Треугольник по трём вершинам | `isEquilateral()` — проверка равенства сторон |
| `Square` | Квадрат по четырём вершинам | `side()` — длина стороны |
| `Pentagon` | Пятиугольник по пяти вершинам | `isRegular()` — проверка равенства сторон и углов |
| `PolygonCollection` | Владеющая коллекция фигур различных типов | `add`, `remove`, `clear`, `size`, `at`, `totalMetric`; правило пяти |

Общие возможности:

- `metric()` — виртуальный метод с реализацией в `Polygon`, вычисляет площадь по формуле шнурка;
- `center()` — среднее арифметическое координат вершин;
- `containsPoint(Point)` — лучевой алгоритм с отдельной проверкой попадания на ребро (`EPS = 1e-6`);
- `print()` и `read()` — чисто виртуальные методы, реализованные в наследниках;
- `clone()` — чисто виртуальный метод для полиморфного копирования без срезки объектов;
- свободные `operator<<` и `operator>>` делегируют вызовы виртуальным `print()` и `read()`;
- `operator double()` возвращает площадь, `operator==` сравнивает площади с точностью `EPS`;
- проверка корректности геометрии при создании фигур и чтении данных: исключаются вырожденные фигуры, некорректные квадраты и самопересечения пятиугольника.

Виртуальный деструктор `Polygon` обеспечивает корректное удаление производных объектов через `Polygon*`. Методы, не изменяющие состояние (`metric`, `center`, `containsPoint`, `print`, `clone`, тип-специфичные проверки), объявлены `const`. Метод `read` изменяет вершины и поэтому не является `const`. `dynamic_cast` используется для доступа к тип-специфичным методам через указатель на базовый класс.

Класс `PolygonCollection` хранит собственный динамический массив указателей `Polygon**` с полями `data_`, `size_` и `capacity_`. При заполнении ёмкость удваивается. Добавление и глубокое копирование используют `clone()`, удаление освобождает объект и сдвигает указатели. Коллекция владеет созданными копиями и удаляет их в `clear()` и деструкторе. Реализованы конструкторы копирования и перемещения, оба оператора присваивания и деструктор (правило пяти); копирующее присваивание использует copy-and-swap, перемещающие операции объявлены `noexcept`.

## Формат ввода и вывода

Каждая фигура задаётся соответственно 3, 4 или 5 парами координат `x y`. При выводе указываются имя класса, координаты вершин в порядке обхода, центр и площадь. Чтение реализовано виртуальным `read()` с проверкой корректности данных; при ошибке поток получает состояние `failbit`.

Пример вывода:

```text
Triangle 0 0 4 0 2 3 Center 2 1 Area 6
Square 0 0 2 0 2 2 0 2 Center 1 1 Area 4
Pentagon 0 0 1 0 2 1 2 2 0 1 Center 1 0.80000000000000004 Area 2.5
```

## Сборка

Проект собирается через CMake 3.20+ с использованием стандарта C++20 и флагов `-Wall -Wextra -Wpedantic` (для MSVC — `/W4`). При первой конфигурации CMake загружает Google Test v1.17.0 через FetchContent; для этого нужен доступ к GitHub.

В PowerShell:

```powershell
cmake -S . -B build-cmake -G Ninja -DCMAKE_BUILD_TYPE=Debug
cmake --build build-cmake
```

Отдельные цели сборки: `polygon` (библиотека), `lab4` (демонстрационное приложение), `lab4_tests` (тесты).

## Запуск программы

```powershell
.\build-cmake\lab4.exe
```

`main.cpp` демонстрирует создание и вывод фигур, добавление их в полиморфную коллекцию, вычисление суммарной площади, применение `dynamic_cast`, копирование, удаление и перемещение объектов коллекции.

## Тесты

Для тестирования используется Google Test (**45 тестов** в шести файлах).

Запуск тестов напрямую:

```powershell
.\build-cmake\lab4_tests.exe
```

Или через CTest:

```powershell
ctest --test-dir build-cmake --output-on-failure
```

В тестах проверяются площадь и центр фигур, равносторонность треугольника, сторона квадрата, правильность пятиугольника, недопустимые и вырожденные фигуры, лучевой алгоритм и точки на границах, потоковый ввод/вывод, операторы сравнения и преобразования, полиморфизм и `dynamic_cast`, добавление и удаление элементов коллекции, глубокое копирование, перемещение, присваивание и обработка неверных индексов.

**Результат:** 45 из 45 тестов пройдены в обычной сборке и в сборке с ASan/UBSan.

## Проверка памяти

Для проверки ошибок обращения к памяти используется AddressSanitizer и UndefinedBehaviorSanitizer со сборкой Clang в MSYS2 CLANG64:

```bash
cmake -S . -B build-asan -G Ninja \
  -DCMAKE_BUILD_TYPE=Debug \
  -DCMAKE_C_COMPILER=clang \
  -DCMAKE_CXX_COMPILER=clang++ \
  -DCMAKE_C_FLAGS="-fsanitize=address,undefined -fno-omit-frame-pointer" \
  -DCMAKE_CXX_FLAGS="-fsanitize=address,undefined -fno-omit-frame-pointer" \
  -DCMAKE_EXE_LINKER_FLAGS="-fsanitize=address,undefined" \
  -DCMAKE_SHARED_LINKER_FLAGS="-fsanitize=address,undefined"
cmake --build build-asan
ctest --test-dir build-asan --output-on-failure
```

**Результат повторной проверки:** Clang 22.1.8 (MSYS2 CLANG64), **45 из 45 тестов пройдены** за 0,96 с. Сообщений об ошибках AddressSanitizer и UndefinedBehaviorSanitizer при выполнении тестов нет. Сборка приложения и тестов завершилась успешно; единственное предупреждение относится к сторонней библиотеке Google Test (`gtest-printers.h`, преобразование `char8_t` в `char32_t`), а не к исходникам лабораторной.

Проверка ASan/UBSan не гарантирует обнаружение всех ошибок, а обнаружение утечек памяти на Windows зависит от поддержки LeakSanitizer.
